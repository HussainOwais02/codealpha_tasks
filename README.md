# Advanced GPA/CGPA Calculator

A robust, console-based C++ application designed to help students track their academic performance. This project was developed as part of the **CodeAlpha Internship**.

## Features
- **Student Profile:** Captures the student's name for personalized reporting.
- **CGPA Integration:** Allows users to input their previous CGPA and total credits earned to calculate their new overall standing.
- **Semester Analysis:** Supports up to 20 courses per semester.
- **Error Handling:** Robust validation for letter grades (A-F), credit hours, and CGPA ranges.
- **Professional Formatting:** Outputs a clean, tabular summary of courses and grades.

## Grading Scale
The system uses a standard 4.0 scale:
* **A/A+**: 4.0 | **A-**: 3.7
* **B+**: 3.3 | **B**: 3.0 | **B-**: 2.7
* **C+**: 2.3 | **C**: 2.0 | **C-**: 1.7
* **D**: 1.0 | **F**: 0.0
